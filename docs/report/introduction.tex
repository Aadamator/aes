The Advanced Encryption Standard (AES) is a widely used symmetric block cipher that encrypts data in fixed-size blocks through a sequence of round transformations. This report traces how our initial “naive” AES implementation was iteratively refined, with a focus on improving efficiency across each version.

Each implementation was written in C, which was chosen because it keeps the code close to the reference specification while still allowing low-level optimizations, each member of group was already familiar with it, and because it is relatively platform-independent.

To verify correctness, each implementation was tested against a known plaintext and its corresponding ciphertext, which served as test vectors throughout development. 

Finally, the performance of each implementation was benchmarked against a production-grade AES-128 library to evaluate how the optimizations affected efficiency in practice.
